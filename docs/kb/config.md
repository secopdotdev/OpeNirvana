# Configuration

## Environment variables

All configuration is driven by a single `.env` file generated from `.env.example`. Run `python3 scripts/gen-secrets.py` to populate all blank secret slots with cryptographically secure random values. Use `--set KEY=VALUE` to set a specific variable if currently empty. The script never overwrites human-set values.

Key variable groups (see `.env.example` for the full canonical list):

| Variable | Required | Default | Description |
|---|---|---|---|
| `TAILSCALE_AUTHKEY` | yes | — | Tailscale auth key (ephemeral + reusable-disabled recommended) for the ingress sidecar |
| `CLOUDFLARE_API_TOKEN` | yes | — | Cloudflare API token with DNS edit rights; used by Caddy for ACME DNS-01 challenge |
| `HOST_PUBLIC_IP` | yes | — | Host's public IP; used in Caddyfile `@cloudflare` matcher for source-IP restriction |
| `POSTGRES_PASSWORD` | yes | — | Master Postgres password (generated by `gen-secrets.py`) |
| `REDIS_PASSWORD` | yes | — | Redis auth password (generated by `gen-secrets.py`) |
| `AUTHENTIK_SECRET_KEY` | yes | — | Authentik signing key (generated by `gen-secrets.py`) |
| `AUTHENTIK_BOOTSTRAP_TOKEN` | yes | — | Authentik API token for initial provisioning; kept for lockout recovery |
| `AUTHENTIK_BOOTSTRAP_EMAIL` | yes | — | Admin email for Authentik bootstrap |
| `AUTHENTIK_BOOTSTRAP_PASSWORD` | yes | — | Admin password for Authentik bootstrap |
| `BAO_ADDR` | cond. | — | OpenBao server address; required only when `--target=bao` or running `bao-bootstrap.py` |
| `BAO_KV_MOUNT` | cond. | — | OpenBao KV v2 mount path; required with `BAO_ADDR` |
| `PROTONVPN_WIREGUARD_PRIVATE_KEY` | cond. | — | WireGuard private key for ProtonVPN; required for `--profile media` (gluetun) |
| `WAZUH_API_PASSWORD` | yes | — | Wazuh API and indexer password (generated by `gen-secrets.py`) |
| `CROWDSEC_BOUNCER_API_KEY` | yes | — | Crowdsec bouncer key for the Caddy bouncer plugin (generated at stack startup, fetched by `gen-secrets.py --apply`) |
| `NEXTCLOUD_ADMIN_PASSWORD` | yes | — | Nextcloud admin password (generated by `gen-secrets.py`) |

## Config files

| File | Format | Purpose |
|---|---|---|
| `unified-stack/.env.example` | bash-style `KEY=VALUE` | Canonical config shape; template for operator-created `.env`; the source of truth for all supported variables |
| `unified-stack/docker-compose.yml` | Docker Compose v3 YAML | Service definitions, network topology, volume mounts, profile assignments |
| `unified-stack/templates/caddy/Caddyfile` | Caddy config DSL | Reverse proxy routes, TLS, WAF (Coraza), Crowdsec bouncer, rate-limit, forward-auth, cache (Souin) |
| `unified-stack/templates/crowdsec/acquis.yaml` | YAML | Crowdsec log acquisition config (which log sources to tail) |
| `unified-stack/templates/wazuh/decoders/` | Wazuh XML | Custom Wazuh decoders (synced to host by `maintain.py wazuh`) |
| `unified-stack/templates/wazuh/rules/` | Wazuh XML | Custom Wazuh detection rules (synced to host by `maintain.py wazuh`) |

## `.env.example`

The canonical config shape lives at `unified-stack/.env.example` in the repository. It is the source of truth for all supported variables. Running `python3 scripts/gen-secrets.py` against a copy named `.env` populates all blank secret slots. The `--set KEY=VALUE` flag sets a single key if blank (used for `HOST_PUBLIC_IP`, `TAILSCALE_AUTHKEY`, and `CLOUDFLARE_API_TOKEN` which have no safe default).

Key sections in `.env.example`:
- Host network / DNS configuration (`HOST_PUBLIC_IP`, `BASE_DOMAIN`, `TAILNET_DOMAIN`)
- Tailscale and Cloudflare credentials
- Postgres and Redis passwords (all generated)
- Authentik admin bootstrap and signing key (all generated)
- Per-app OIDC client IDs and secrets (provisioned by `set-auth.py oidc`)
- Wazuh and Crowdsec credentials (generated; Crowdsec bouncer key fetched post-startup)
- OpenBao coordinates (optional; only when using `--target=bao`)
- ProtonVPN WireGuard key (optional; only when using `--profile media`)
- Nextcloud and productivity app credentials (all generated)

## Docker Compose profiles

| Profile flag | Services included |
|---|---|
| *(none — core)* | Authentik (server + worker + proxy + migration), Nextcloud + notify-push, Wazuh (manager + 3× indexer + dashboard), Falco, Zeek, Crowdsec, Caddy, Postgres, Redis, Tailscale-ingress, OpenBao, autoheal, socket-proxies |
| `--profile media` | Jellyfin, Jellyseerr, Prowlarr, Radarr, Sonarr, Lidarr, qBittorrent, FlareSolverr (all routed through gluetun ProtonVPN WireGuard tunnel) |
| `--profile apps` | ntfy, Tandoor, Vikunja, AFFiNE |
| `--profile siem` | Wazuh SIEM (manager + indexer + dashboard) |
| `--profile runtime-sec` | Falco runtime security |
| `--profile netmon` | Zeek network monitoring |

## Host directory layout

All persistent data lives under `/dock/` on the host, owned `1010:1010` (svc-user:media), mode `770` except DB directories which are `700`:

| Path | Purpose |
|---|---|
| `/dock/conf/` | Static config files bind-mounted read-only into containers |
| `/dock/data/` | Application state (Nextcloud files, Wazuh data, Jellyfin metadata, etc.) |
| `/dock/db/` | Postgres and Redis data directories (mode 700) |
| `/dock/tail/` | Tailscale persistent state |
| `/dock/backups/` | Postgres backup archives produced by `maintain.py backup` |
